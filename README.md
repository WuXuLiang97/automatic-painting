1. 需要VMware虚拟机win7系统，开启vnc<br>
   ![](README_IMAGE/vnc_settings.png)<br>
2. 游戏窗口开启磁吸放置到左上角，并锁定窗口<br>
   ![](README_IMAGE/game_settings-7.png)<br>
3. 游戏设置好<br>
   ![](README_IMAGE/game_settings.png)<br>
   ![](README_IMAGE/game_settings-2.png)<br>
   ![](README_IMAGE/game_settings-3.png)<br>
4. alt的位置放个后跳，以识别技能状态，有没有释放完毕。ctrl放能击杀b0ss的技能，打深渊的话快捷物品1还是快捷物品2放红药<br>
   ![](README_IMAGE/game_settings-4.png)<br>
5. 刷风暴逆鳞需要把金绿放第一格<br>
   ![](README_IMAGE/game_settings-5.png)<br>
6. 传送阵设置<br>
   ![](README_IMAGE/game_settings-6.png)<br>
7. 角色称号设置成基础达标者<br>
   ![](README_IMAGE/game_settings-8.png)<br>
8. 游戏一键聚物键为tab,回赛利亚房间键为delete

10. app_server.py为跑yolo、paddleocr的程序入口<br>
