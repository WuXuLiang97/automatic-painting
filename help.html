一、依赖安装说明

yolo依赖：

pytorch官网

paddle：

paddle官网

建议先安装服务器app_server.py的依赖，调试好服务器后再安装脚本app.py的依赖，否则可能造成依赖冲突

永久配置清华源，安装依赖包可快速下载：

# 设置清华源为默认镜像
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

GTX1660及以上显卡（推荐配置）：

使用CUDA 11.8版本的PyTorch和Paddle GPU版，无需额外安装CUDA Toolkit

1. 安装GPU版PyTorch：

pip install torch==2.7.1 torchvision==0.22.1 torchaudio==2.7.1 --index-url https://download.pytorch.org/whl/cu118

2. 安装GPU版Paddle：

python -m pip install paddlepaddle-gpu==3.2.0 -i https://www.paddlepaddle.org.cn/packages/stable/cu118/

旧显卡（如GTX10系列及以下）：

使用CUDA 11.3版本的PyTorch和CUDA 11.2版本的Paddle GPU版，需额外安装CUDA Toolkit 10.2

旧版本安装请参考对应官网的历史版本列表（PyTorch官网：点击跳转；Paddle官网：点击跳转）

请注意app_server.py的导入依赖，比较旧的显卡导入 cv_inference_server_2.py,否则导入另外那个模块

二、程序使用帮助

1、环境准备：VMware虚拟机Win7系统

需在Win7虚拟机中开启VNC服务，确保远程连接正常

2、游戏窗口基础设置

游戏窗口开启磁吸功能，放置到屏幕左上角，并锁定窗口（防止误拖动）

3、游戏核心参数设置

4、技能按键配置（关键识别设置）

• Alt键：设置为「后跳」（用于识别技能释放状态，判断是否释放完毕）
• Ctrl键：设置为「能击杀BOSS的技能」（核心输出技能）
• 深渊模式：快捷物品1或2放置「红药」（应急回血）

5、物品栏与特殊场景设置

• 刷「风暴逆鳞」：需将「金绿柱石」放在物品栏第一格，刷「黄龙大会」：需将「无尽的永恒」放在物品栏第二格
• 一键聚物键：设置为Tab
• 回赛利亚房间键：设置为Delete
• 角色称号：设置为「基础达标者」（确保识别稳定性）

6、传送阵设置，必须按照这个顺序摆放

7、角色称号设置

8、程序入口说明

• app.py：主程序入口（负责核心逻辑执行）
• app_server.py：服务端入口（负责YOLO目标检测、PaddleOCR文字识别）
