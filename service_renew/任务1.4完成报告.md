MAX_IMAGE_SIZE = 50 * 1024 * 1024  # 50MB，防止内存溢出攻击

## 实现详情

### 1. 图像大小限制

**位置：** `_receive_message` 方法

**实现：**
- 在接收图像数据前检查 `image_size`
- 如果超过 `MAX_IMAGE_SIZE`，立即返回错误
- 不接收实际数据，节省带宽和内存
- 返回清晰的错误信息

**代码：**
```python
if image_size > MAX_IMAGE_SIZE:
    logger.warning(f"图像大小超过限制: {image_size / 1024 / 1024:.2f}MB > {MAX_IMAGE_SIZE / 1024 / 1024:.2f}MB")
    header["_size_exceeded"] = True
    header["_error"] = f"图像大小超过限制（最大 {MAX_IMAGE_SIZE / 1024 / 1024:.0f}MB）"
    return header, None
```

### 2. 请求类型验证

**位置：** `_handle_client` 方法

**实现：**
- 检查请求类型是否在 `VALID_REQUEST_TYPES` 中
- 无效类型返回错误，包含有效类型列表
- 记录警告日志

**代码：**
```python
if req_type not in VALID_REQUEST_TYPES:
    logger.warning(f"无效的请求类型: {req_type}")
    result = {"error": f"无效的请求类型: {req_type}，有效类型: {', '.join(VALID_REQUEST_TYPES)}"}
    self._record_metric(req_type, 0.0, False, True)
    self._send_response(conn, result, req_type)
    continue
```

### 3. 连接数限制

**位置：** `_listen` 和 `_handle_client` 方法

**实现：**
- 使用 `_active_connections` 计数器跟踪活跃连接
- 使用 `_connections_lock` 保护计数器
- 在 `accept` 时检查连接数
- 超过限制时立即关闭连接
- 连接关闭时（正常或异常）都减少计数

**代码：**
```python
# 在 _listen 中
with self._connections_lock:
    if self._active_connections >= MAX_CONNECTIONS:
        logger.warning(f"连接数已达上限 ({MAX_CONNECTIONS})，拒绝新连接: {addr}")
        conn.close()
        continue
    self._active_connections += 1

# 在 _handle_client 的 finally 中
with self._connections_lock:
    self._active_connections = max(0, self._active_connections - 1)
```

### 4. JSON 头部验证

**位置：** `_receive_message` 方法

**实现：**
- 验证头部大小不为0
- 验证头部大小不超过 `MAX_HEADER_SIZE`
- 无效头部时记录日志并返回 `None, None`

**代码：**
```python
if header_size > MAX_HEADER_SIZE:
    logger.warning(f"头部大小超过限制: {header_size} > {MAX_HEADER_SIZE}")
    return None, None
if header_size == 0:
    logger.warning("头部大小为0")
    return None, None
```

## 安全特性

### 防护措施

1. **内存溢出防护**
   - 限制图像大小（50MB）
   - 限制JSON头部大小（1MB）

2. **DoS 攻击防护**
   - 限制并发连接数（100）
   - 快速拒绝无效请求
   - 连接关闭时正确释放资源

3. **输入验证**
   - 验证请求类型

   - 验证数据大小

4. **错误处理**
   - 记录安全相关日志
   - 返回清晰的错误信息
   - 不泄露内部信息

## 注意事项

1. **限制值调整**
   - `MAX_IMAGE_SIZE` 可根据实际需求调整
   - `MAX_CONNECTIONS` 可根据服务器性能调整
